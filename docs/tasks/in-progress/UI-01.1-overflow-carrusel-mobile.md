# UI-01.1 — Corregir overflow del carrusel en mobile

Estado: completed.

## Cambio

Se limita el ancho de la sección y del viewport del carrusel y se recortan los laterales dentro del contenedor. La columna explícita `minmax(0,1fr)` evita que el contenido expanda el grid. Se conserva el máximo desktop de 960 px, las tarjetas proporcionales y todos los gestos, selección lateral, indicadores, teclado y transiciones. El contorno de foco se dibuja hacia dentro del recorte.

No cambian copy, estructura, estilos base ni otras secciones. Sólo estilos locales y una clase de viewport. Sin nuevos tests para este ajuste de presentación reversible: se ejecutan los existentes de landing. Sin screenshots, regresión visual ni inspección visual automatizada.
